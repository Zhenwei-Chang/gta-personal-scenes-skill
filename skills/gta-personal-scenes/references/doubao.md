# 豆包使用方式

核对日期：2026-10-04。

## 豆包工作：自定义 Skill

飞书官方介绍说明，豆包工作可创建自定义技能、导入本地技能文件，并在对话中选择技能；也提供参考素材的图片生成与编辑能力。具体入口和生图权益依客户端与账号而定。[官方说明](https://www.feishu.cn/content/article/7677519271848610746)

本项目提供标准 `SKILL.md` 文件夹，包含名称、描述、执行指令及参考文档。官方说明未公布本地导入的精确 ZIP 层级或 `SKILL.md` 解析规范，本包尚未在使用者的豆包客户端完成安装验证。

实际操作：

1. 在当前豆包工作客户端找到技能管理或自定义技能入口。
2. 如果有本地导入，按文件选择器支持的格式导入本项目的 Skill 文件夹或 `gta-personal-scenes.skill.zip`。ZIP 顶层放置 `SKILL.md`，同级包含 `references/` 和 `agents/`。
3. 如果导入器不接受该结构，使用“新建自定义技能”：名称填“GTA 个人生活场景”，描述可取 `SKILL.md` 的 `description`，执行指令粘贴 `SKILL.md` 正文，并附加 `references/` 中的文档。
4. 如果该入口不能读取支持文档，把仓库 `adapters/doubao-instructions.md` 的全文作为执行指令；该文件是无需跨文件读取的独立版本。
5. 在支持图片创作的对话中选用此技能，上传本人照片与要求。需要换主角时另上传原场景；有认可的人物基准时一起上传，并说明图片顺序。

可输入：

> 使用 GTA 个人生活场景技能。图 1 是我的照片。请把我做成 GTA San Andreas 风格游戏人物，先做休闲和篮球两套衣服，每套单独一张 1:1 图片，不加标注。

不要把本机文件路径当作已上传附件。安装 Skill 不会自动让豆包读取电脑上的私人照片，也不会自动接通模型 API。

## 普通豆包：复制指令

普通豆包官方页面说明可定制智能体，但没有在此来源中说明直接导入 `SKILL.md`。[官方功能介绍](https://www.doubao.com/legal/feature_intro)

在支持图片生成的普通豆包对话中，粘贴 `adapters/doubao-instructions.md` 全文，再上传照片并追加自己的场景要求。若当前账号有自定义智能体指令输入区，也可以把它存入指令区；能否在该智能体里直接生图，以当前界面能力为准。

对话只能生成提示词时，将它给出的完整提示词和同样的参考图送入可用的图片创作入口。需要跨对话继续人物身份时，重新上传认可的角色基准，不依赖跨对话隐式记忆。

## 可选开发者接入

若使用者另行要求 API 自动化，可接火山方舟 Seedream。官方图片 API 支持图像参考，相关教程演示了多参考图服装更换和人物多场景生成。[图片 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh&redirect=1)，[官方教程](https://docs.volcengine.com/docs/ark/seedream-4-0-5-0?lang=zh)

依账号配置可用模型或 Endpoint ID，并核对该型号的参考图数量、尺寸与组图参数。保持一次一个场景，按本 Skill 分配参考图角色；不要把某型号的参数直接套到所有版本。

本仓库是工作流与提示词 Skill，不包含 API 密钥、计费调用程序或豆包内部接口。图像工具由宿主提供。
